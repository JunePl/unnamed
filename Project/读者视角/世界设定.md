## 一、地理

- **卡萨林王国**：故事所在国，下辖**七大州**。纪年用「新历」（《嘶吼》的落款是新历 138 年）。
- **王都**：王国中心，执政厅、王室、皇家学院本部所在。**里斯特王都艺术学院**也在王都。**盐区**是王都早年码头工人住的老地界，潮湿，腥味混着阴沟的霉味。
- **提耶林**：**卡萨林七大州中距离王都最近的一个州**。整体偏穷——阿涅丝在贫民区抬头时，看见「提耶林区像是一整块向下倾斜的巨大滑梯，而他们所站的位置，正是所有东西最终都会滑落、堆积的最底端」。
  - **约尔西德城**：提耶林州最繁华的城市，又称**提耶林西城区**。拉尔贝大街在城北，与执政厅的协办点很近，住的是弗朗西斯、马蒂亚斯这样的人。
  - **港口区**：治安极差，走私、斗殴、私造灵质品什么都有；**滨河街**、中心商城、奥斯伯恩的铺子都在这一带。
  - **橡木街**：阿尔温事务所（779A）和住处所在。
  - 提耶林平均月收入不到三千，「想过得去」需要接近五千；买栋房子不到一百万。
- **恩利尔**：**王都南边的一个州城**，比城里干净也安静。蒙特家的宅子在这里，**蒙特家的大哥是恩利尔城的代表执政官**。从卡萨林北站坐悬浮灵车三等车厢八卡币、五十分钟到。
- **西米尔郡 / 西边的州城**：比提耶林更偏远。流浪汉被驱逐的目的地，在他们口中是「把人往死路上赶」。
- **外部地名**：
  - **陶格林（联合体）**：**诺菲尔制药**的产地（铸世源流灵使抱团组成的集团，靠特制伤药赚钱）。陶格林人的外貌特征是**深绿瞳孔中心带黑**。
  - **沃伦**：科技发达，造浮空车、手环、「我聊」和造梦仪，也发行天秤榜单。传闻那边的实验室有**不需要灵晶、不需要术法的新药**（阿尔温称之为「化学」）。
  - **霍尔姆公国**：矮人主导的国家，在卡萨林东边；卡萨林境内的矮人占超过百分之十五。
  - **赫利亚（远北联合城邦）**：治安糟糕，「有着真正的自由」。近三个月七起命案的发生地。
  - **大陆中南部**：传闻有一个**兽人／猫人族的组织**（卢卡斯说是兽人，阿尔温后来说是猫人族），专挑人类多的城市下手。

## 二、灵的体系

- **真灵**：与人签订「灵契」的超自然存在。被真灵认可的人即**灵使**，身上会浮现**灵纹**。真灵进入宿主时，**名字会直接被写进脑子里**。
  - 阿尔温的原话：**「不到百分之五的机会难道还能人人都是灵使吗」**——绝大多数人是**无灵者**。
  - 无灵者也能感应灵质、能通过灵晶获取灵能（「几乎是个人类就能做到」），但**没有真灵的共鸣，就永远停在无灵者的水平**。
- **序**：真灵的位阶，正文统一用「一序／二序／三序……」。已知：
  - 三序在整个卡萨林**不超过百人**（华尔德语）；**整个提耶林的三序只有四个人**（阿尔温语）。
  - **四序**是「屈指可数」的级别（安东尼奥·莫兰蒂）。
  - **一序灵使的补贴是零**——补贴从**二序**开始，而且必须为贵族服务。
- **灵质**：一切生物灵魂的原质。**只会从彼界流向现实，被消耗后自然回归彼界**——阿尔温的比喻是「瀑布从高处流向低处，哪里有水可以违背引力向上流」。死亡时会从七窍逸散。
  - **无属性只会出现在无意识的飘散**（第一章的关键判据）。
  - 把灵质装进体内**一旦出现排异现象「那可不是闹着玩的」**（灵晶义体者后颈必须刻编号，就是怕暴走）。
- **灵值 / 灵能**：量化单位是「灵点」，可被仪器测出、可耗尽。阿尔温觉醒前的上限是 **98**，觉醒后是 **289**。
- **灵痕**：真灵使用后留下的痕迹，有颜色，会按曲线均匀衰减。
  - **黑色对应渊秘源流，卡萨林的渊秘源流真灵屈指可数。**
  - **灵痕残留不均匀、一闪一闪的，是真灵失控的早期症状。**
  - 灵痕颜色辨识需要至少二序的灵力感知基础，或二序以上的分析设备。
- **源流**（正文已出现）：**织命源流**（又称生命源流，治疗系稀缺属性；阿涅丝的小织、阿尔温的蚀析）／**辉耀源流**（弗朗西斯、拉吉）／**铸世源流**（艾伦、诺菲尔制药）／**缚誓源流**（老彼得）／**渊秘源流**（黑色，拉德斯）／**终焉源流**（华尔德的「幻灭」）。
- **彼界**：灵能的源头。**世界各地都存在彼界裂缝**，灵质由此流入现实。
  - 在彼界是灵魂体（现实的伤不影响行动），灵能会自动汩汩灌进身体，但**吸收速度有限**。
  - **灰烬平原 / 灰烬漩涡**：铅灰的天、灰白的地、黑色结晶柱；漩涡缓慢移动，中心是紫红色结晶柱，**约两天刷新一次地形**。
  - **魅影灵**：野生真灵，灰色人形剪影、白色弧形面具、滑移移动、发射黑灰色光球，**弱点是面具**；打碎后化作灰光被吸收。**和生物绑定的初生真灵是它们最爱的美食。**
  - **灵晶柱**：彼界灵能汇聚结成的结晶，野生灵会啃食。
  - **彼界之芯**：彼界正中央那根大柱子，**天秤榜就刻在上面**。
  - **「彼界的隐秘在现实里面会自己消失。」**
  - **彼界之限**：黑暗中那个声音的说法——「彼界会自动排斥一些人，也就是为什么你至今没有真灵」。（此说仅出自那个声音，未经第三方证实。）
- **天秤榜**：真灵排名榜，共 **199 位**，刻在彼界之芯上，由沃伦发行榜单。顶端有**柱位**、更上有**冠位**，柱位各有名号（如**「太阳」**）。被称作「恶意编排灵使和真灵的榜单」。哈罗德的司契是第 198 位。
  - 另有一套**「刃位」**用于人（维辛妮是**刃位七十八**）。
- **灵晶**：
  - **加工过的灵晶**人类才能吸收成为灵能，但贵得离谱。
  - **未经加工的生灵晶**（在靠近彼界裂缝的地方才能找到）可直接吸收、**一颗相当于一序、够从空灌到满**，但**会加速脏器衰竭、极可能被灵质侵袭患上灵晶病**，还有发烧头痛等后遗症；即便如此仍价格不菲。
- **灵遗物**：**在卡萨林被严格管控**。拉德斯用的那一枚只有硬币大小、暗红色、纹路是残破的四角结构，按进胸口后能召出半透明灵体、扭曲空气、腐蚀地面，**并吞噬／免疫火焰类攻击，伤口极速愈合**（阿尔温判断是「吞噬系」）。作用、代价、如何处理——连维辛妮都答「不清楚」。
- **双真灵**：**王国史上留下记载的也是屈指可数**。卡尔罗·维恩兰德身上同时有冷蓝与灰白两种源流的灵痕。
- **渡物型（时空相关）能力**：**在卡萨林罕见得离谱**。可以把物件「渡」进上锁的房间——不是拿进来的，是有人在别处放下、它就出现在这里。

### 与灵相关的病 / 异变
- **阿克曼症**：最近十年才在卡萨林被发现的**非典型人传人的灵质病**，感染原因与根治法都未知。患者会大幅度幻想「自己与神共舞并尝试杀掉所有人」，身体慢慢被灵质腐蚀（从手腕往上出现暗斑）。
  - 靠**灵稳剂**短暂抑制体内一切灵能反应。正规渠道一盒五百、医院每月限开四盒；黑市一盒一百五，**没有批号，没有厂家名字**。医保只报三成——**阿克曼症不在全额报销清单上**。
- **灵晶病**：吸入过量灵质所致（灵晶矿处理厂的工人和他们的孩子），皮肤长蓝绿色晶体。
- **灵变**：真灵失控 → 侵蚀宿主 → 变成变异体。
  - **早期征兆**：灵质残留不稳、指尖发光、力量远超本序、不眠、精神恍惚。
  - **失控向来是三序以上才听说过的事**——所以艾伦（一序）出现这种症状「不正常」。
  - 档案里的灵变**大多不是人类的样子就是奇诡的能量团，既没有器官，也不会主动追猎**——港口区这一次完全不同。

## 三、机构与权力

- **执法局**：
  - 基层是**执法员**（三级 → 二级 → 一级），高阶是**执法使**。**一级执法使拥有先斩后奏的权力，仅次于特级执法使**；特级执法使、执法局局长与**伯爵**同级；伯爵往上是**公爵**（卡萨林只有六个），再往上是执政厅和王室。
  - **结案必须由分析师确认案件的自然性与证据链的合理性**——阿尔温形容这个职位「和历史上曾经存在的侦探一职类似」。
  - **独立灵痕分析师一年只发五十张证件**；四国展期间明令必须有**王都认证**的独立分析师证明才能参与官方任务。
  - 近期出了《**灵痕证据审核标准（修订版）**》，把阿尔温用的「自主适配式灵痕频谱比对法」踢出认证清单——**后被辛吉亚上诉驳回**。
  - 提耶林执法局：局长**辛吉亚**，副局长**莫汉森**。局内另设**监督分部**专管举报申诉。
- **执政厅 / 执政会**：统治核心，任命四国展执行官等要职。**商人联盟是执政厅三大联盟之一，有「眷属名额」**。**安东尼奥·莫兰蒂**是执政厅的人、四序灵使、越序契书的创制者。（阿涅丝的朋友提到「执政厅那三家」。）
- **兄弟会**：**原本就作为潜在的犯罪集团而受执法局注意，但至今没有组织性参与犯罪的证据**，所以一直被放过。第四十四～四十七章后，维辛妮要求王都当局强制搜查。已知成员／关联者：**拉德斯**（渊秘源流、能变脸、持灵遗物）、**面具人**（被称作「兄弟会的马尔克斯先生」）。他们在找**皇室遗失的重宝**。
- **皇家学院**：王都的顶级学府，收灵使直入，设**灵使预备课程**。**提耶林学院**、**提耶林大学院**是另外的学校。
- **医疗与补贴**：灵使重伤治疗、训练损伤全报；**灵使家属的病自费**。一序灵使补贴为零。

## 四、特殊物件 / 科技

- **单片眼镜**：阿尔温的灵质检测仪，靠灵芯自己悬浮，收在一只银白色金属盒里。能显示真灵有无、源流、灵值、环境灵质场密度并给出警告。**是学院导师送的，没有官方认证**（格里尔就是拿这一点做文章的）。
- **灵质枪**：以灵能供弹，按住枪柄凹槽注入灵能可打「**赋能弹**」，一发约五点灵能。阿尔温这把是**华尔德的枪**，十发弹匣。
- **手环 + 「我聊」**：通讯与支付设备，可语音、群发、显示虚拟屏幕；**强灵质场会把所有频段压死**。
- **造梦仪**：近几年兴起的娱乐设备，戴上睡一觉就能做想做的梦，**贵得离谱**（约纳斯要不吃不喝干好几个月）。广告词是「**幸福触手可得**」。有专门的体验馆——**馆里的人在做粉色的海的梦，馆外过道上蹲着一排眼神呆滞、付不起钱的人，其中几个骨瘦嶙峋的还戴着简陋的仪器不时抽搐**。
- **越序契书**：**执政厅的安东尼奥·莫兰蒂所创**，只发给**二级以上立过功**的灵使。**以燃烧五十年寿命为代价提升一序**，效力约十分钟；**连着用两次必死无疑**。反噬时鼻孔、嘴角、耳道乃至眼睛出血。
- **诺菲尔制药·三序**：陶格林联合体铸世灵使集团出的伤药，**市价七八千一瓶**，倒在见骨的伤口上能当场长出肉芽。
- **真灵卡片**（神殿所出）：骨质手感，卡上的异文会自动变成读得懂的文字。已知：**【死命织礼·分支推演·S 级】**、**【体温气味·C 级】**。
- **入梦头盔**：流浪汉盖着报纸躺长椅时戴的东西，「一躺就是一个冬天」。
- **灵纹玻璃**：一块四百，四国展前商铺翻新时往橱窗上嵌。

## 五、当下的时局

- **四国展将近**：四国联合艺术展，**经国王陛下亲自批准如期举行**，约一个月后在王都开幕。规定**不得擅自调整展品安排或场馆布置**，如需变更须逐级上报至一级执法使审批。提耶林作为离王都最近的州，被要求一个月内「把自己打扮成值得办四国展的样子」。
- **经济与治安**：经济大萧条，补贴发不下来；奢侈品店改成卷帘门加防盗锁照样被抢，**半个月里同一条街就出了好几起**；执法局懒得抓——「抓进去拿什么养这些人？普通的治安官自己还吃不起饭呢」。入冬后**丧葬场固定在日落后回收街上的尸体**。
- **驱逐流浪汉**：四国展筹备期间主干道市容整治（落款提耶林城防局），**周末之前提耶林地界上一个要饭的都不许留**，全迁往西边州城。
- **新月教**：**这两年才在卡萨林兴起的教派**，**给不少流浪汉和孤儿提供庇护和免费食物**。信徒念**「新月母神」**（「新月母神啊，保佑我们平安无事」），会邀人「有空、不嫌弃的话也来教会看看」。流浪汉说提耶林「好歹挨着王都，**还有母神帮助**」。慈善活动会送**纹着红色月亮的绒祈玩偶**。
- **王都连环命案**：王都这两年接连出命案，**凶手连个影子都没有**。坊间传闻**死者出事之前，街坊都说在他家门口见过一只黑猫**。**王都平民死亡率已上升到 0.1 以上。**
- **城里黑猫变多**：这两年城里的黑猫多得邪门，都是**琥珀色瞳孔**。（雷纳德在王都盐区喂过一只；阿涅丝在提耶林街头见过一只；阿尔温醒来时办公室里蹲着一只——门窗是他自己锁的，**而它走后他捡到的那块黑色结晶也不见了**，后来他手里多了一根黑色猫毛。）
- **各国异动**：北边几个国家军演频繁，「这阵子四下里都不太对劲」，偏赶上四国展的节骨眼。
- **赫利亚远北七起命案**：过去三个月、远北联合城邦的六个城市、七起案件，**全部是亲人杀害亲人**（儿子杀父亲、妹妹杀哥哥、兄弟杀兄弟），死者多有政治身份。官方统一定性并禁止深查；评论区留言大批被系统折叠。
  - 内部简报另载：曾有三名独立调查员试图深查，**两人失踪、一人退出**；**七起案件现场均检出淡紫色粉尘残留，粒径比普通灵质粉尘小一个量级**。
  - 另有传闻：一个**没有国籍的非灵能者佣兵**拒绝接受官方结论，在死者家地板缝里找到了不该在那里的东西。
- **各地「奇特术式的痕迹」**：王都命案之外，各地近来冒出不少奇特术式的痕迹，性质未明。
- **王都临时监察团**：为预防四国展期间的一切威胁而组建，**要从七个州城调「最好的人才」**——查的明明是王都的案子，为什么要从各地调人，辛吉亚避而不答。阿尔温已被以分析师身份报了进去。
- **天秤榜异动**：**柱位多了一个人，名叫「太阳」**，据说是**霍恩家那位当年被封公爵后销声匿迹的小将军**——**没完成仪式却升上了四序**。执政厅试图保密，但沃伦发行的榜单封锁不住。

## 六、时间线索

- 故事主体在秋末冬初（**十一月**：办公室的警报盒读数标着「十一月二十三日」；医院外「十一月的风格外冷冽」；港口中心商城挂着开海节的灯笼）。《嘶吼》的落款是**新历 138 年**。
- 全书主线约十五天：马蒂亚斯案发（第一夜）→ 三天调查期 → 被解聘、当夜港口区灵变 → 觉醒、进彼界 → 次日与阿涅丝、收到向日葵信 → 再一天笔录 → 再一天发现祭坛、收到律师的纸袋 → 次日清晨去恩利尔 → 再次日葬礼与站台伏击 → **七天后**的酒会与天台。
- 阿涅丝一个月后去王都皇家学院本部；四国展约一个月后开幕；阿尔温说「过两天也会来王都」。
